## Your delivery, step by step

Most teams do these five steps. chant writes each step as a job in GitHub, GitLab or Forgejo. You keep the steps you have and add the ones you need.

1. Build and test

   Each change is built and tested.

2. Plan

   See exactly what will change before it happens.

3. Approve

   Someone approves that exact change. Every approval is recorded.

4. Release

   The change goes out. For software, chant signs and publishes the release.

5. Watch

   Know what is running and when it changes.

## Terraform and Pulumi are optional

chant writes each cloud's own format, such as CloudFormation. The cloud runs it, and there is no state file.

- **Clear ownership** Each resource carries a label that names its team. chant never deletes anything without one.
- **No waiting** Teams change different resources at the same time. There is no shared lock.
- **Your IAM** The cloud permissions you already have are the gate. There is no extra tool to manage.
- **No lock-in** If you stop using chant, you keep everything it wrote.

</Home>
