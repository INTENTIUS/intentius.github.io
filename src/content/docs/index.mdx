## Nothing changes while we look

The audit runs [behold](https://intentius.io/behold/) and `chant audit` with access you grant for the session only. That means a read-only cloud role, a Kubernetes `view` role and read access to your repos. No agent is installed and no state file moves. You keep the graphs when we finish.

## Built on open source

Every tool we use is open source and stays with you when the work ends.

- [behold](https://intentius.io/behold/) draws the estate
- [chant](https://intentius.io/chant/) runs lifecycles and writes CI jobs
- [terragucci](https://intentius.io/terragucci/) governs Terraform and OpenTofu
- [plywood](https://intentius.io/plywood/) governs Pulumi
