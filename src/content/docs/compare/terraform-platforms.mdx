## The tools in these tables

- terragucci plans and applies Terraform, OpenTofu and Terragrunt from pull requests, as jobs in your own CI.
- choudoufu is a build of OpenTofu that records each resource's owner on the resource itself.
- plywood runs Pulumi previews and updates from pull requests, as jobs in your own CI.
- plunge is a fork of Pulumi that keeps one record per resource, so two updates to one stack need not wait for each other.
- behold draws the whole estate as one picture coloured by drift. It only reads.
- chant writes infrastructure as typed code and checks it before anything runs.
